# CEPRA

**Control de Equipos, Préstamos y Recepción en Almacén** — sistema de inventario y préstamos de equipo para los eventos de Gaming Partners (GamingFest, Gamergy, etc.).

## Estado

En arranque. Aún no hay código de la aplicación.

## Stack previsto

- Next.js (App Router) + TypeScript + Tailwind
- Supabase (Postgres, Auth, Storage, Realtime)
- Despliegue en Vercel
- Aplicación web progresiva (PWA) para teléfono, tablet y PC

## Forma de trabajo

- `main` siempre estable; los cambios entran por ramas (`feat/...`, `fix/...`).
- Commits en español con formato `tipo: descripción` (ej. `feat: alta de equipos`).
